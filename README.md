## 📌 About This Repository

This repository documents a **self-driven 60-day learning challenge** focused on building **practical, job-ready data skills**.

Instead of relying on paid platforms or passive learning, this project emphasizes:

* Real-world problem solving
* Consistent daily execution
* End-to-end data workflows
* Public proof of skills

---

## 🎯 Objective

To transition into a **Data Analyst / Business Analyst role** by:

* Strengthening core data skills
* Solving practical business problems
* Building a strong, visible portfolio
